Gambar 4: Arsitektur Dashboard Administratif dan Analisis Sistem

Alur arsitektur untuk otentikasi RBAC lapis ganda, agregasi data KPI sistem, moderasi akun pengguna dengan proteksi anti-lockout, dan jembatan manajemen lintas modul.

1. Penjaga Gerbang RBAC 01
Penjaga Otentikasi Sesi
Mengevaluasi $_SESSION['user_id']. Jika kosong, redirect pengguna belum login ke login.php.
require_login()
↓
Verifikasi Otoritas Peran
Mengevaluasi $_SESSION['role'] === 'admin'. Jika customer biasa, tolak dengan HTTP 403 Forbidden.
require_admin()
↓
Tampilan Dashboard Admin
Layar utama eksekutif menampilkan KPI bisnis, peringatan stok menipis, dan transaksi terkini.
admin/dashboard.php
↓
Isolasi CSS Administratif
Stylesheet terdedikasi mengatur tata letak sidebar admin, kartu ringkasan metrik, dan tabel data.
assets/css/admin.css
2. Mesin Analisis & KPI 02
Agregator Total Pendapatan
Menghitung omzet kotor di luar pesanan yang dibatalkan melalui kueri agregat SQL SUM.
SUM(total_amount)
↓
Penghitung Volume Pesanan
Mengagregasi total order yang dikelompokkan per status (pending, paid, shipped, completed, cancelled).
COUNT(*) GROUP BY status
↓
Penghitung Akun Pengguna
Menghitung total akun pelanggan terdaftar dan jumlah personel tim administrator aktif.
COUNT(id) FROM users
↓
Filter Peringatan Stok Rendah
Menyaring inventaris WHERE stock <= 5, memberi sinyal peringatan kepada admin untuk restock.
WHERE stock <= 5
3. Moderasi & Proteksi Sesi 03
Direktori Akun Pengguna
Daftar seluruh pengguna dengan inspeksi peran, tanggal registrasi, dan tombol tindakan.
admin/manage_users.php
↓
Promosi & Demosi Peran
Memberi wewenang admin untuk mengubah hak akses akun pengguna antara customer dan admin.
UPDATE users SET role = ?
↓
Penjaga Anti-Lockout
Kondisi: target_user_id === $_SESSION['user_id']
• AKUN SENDIRI: Tolak aksi, tampilkan pesan: "Anda tidak dapat mengubah status atau menghapus akun aktif sendiri."
• PENGGUNA LAIN: Terapkan pembaruan hak akses peran.
4. Jembatan Lintas Modul 04
Jembatan Inventaris Katalog
Akses manajemen langsung untuk mengelola kategori barang dan inventaris produk (CRUD 1).
admin/manage_items.php
↓
Jembatan Dispatch Pesanan
Akses manajemen antrean order, verifikasi koordinat GPS, dan pembaruan kurir pengiriman (CRUD 2).
admin/manage_transactions.php
↓
Tabel Data W3C Strict
Semua metrik tabel dan elemen formulir mematuhi sintaks lowercase dan atribut berpasangan tanda kutip.
XHTML 1.0 Strict Valid

Catatan Gambar 4: Portal administratif beroperasi di bawah kontrol akses berbasis peran (RBAC) yang ketat. Mekanisme anti-lockout menjamin administrator aktif tidak dapat mendemosi atau menghapus sesinya sendiri. Kueri agregasi data dieksekusi secara read-only tanpa mengunci tabel saat proses transaksi pelanggan berlangsung.
