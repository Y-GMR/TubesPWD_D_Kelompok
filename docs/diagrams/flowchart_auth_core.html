Login & Role Router2
login.php (XHTML)
Kirim username atau email dan kata_sandi melalui POST.
CSRF token
|
password_verify()
Ambil kata_sandi_hash dari tabel pengguna. Jika gagal -> flash_error ke login.php. Jika cocok -> session_regenerate_id(true).
|
actions/auth_login.php
Set $_SESSION['user_id'], ['peran'], ['foto_profil']. Arahkan ke halaman konsumen, produsen, atau admin.
