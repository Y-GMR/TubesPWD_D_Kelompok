3. Pemroses Atomik ACID 03
Awal Transaksi Basis Data
$pdo->beginTransaction() mengisolasi transaksi untuk mencegah race condition dan pengurangan stok berlebih.
$pdo->beginTransaction()
↓
Pemeriksaan Ketersediaan Stok
Kueri: SELECT stock FROM items WHERE id = :id FOR UPDATE
• STOK KURANG (stok < qty): $pdo->rollBack(), simpan flash error, redirect 302 ke cart.php.
• STOK CUKUP (stok >= qty): Potong stok, sisipkan header & rincian, $pdo->commit().
↓
Komit & Pengosongan Keranjang
Setelah commit(), mengosongkan $_SESSION['cart'] = [] dan redirect pelanggan ke transactions.php.
$pdo->commit() -> unset($_SESSION['cart'])
↓
Restorasi Stok saat Pembatalan
Jika admin membatalkan pesanan: UPDATE items SET stock = stock + :qty memulihkan inventaris.

Catatan Gambar 3: Seluruh operasi checkout dieksekusi dalam transaksi atomik PDO dengan proteksi rollback terhadap race condition dan penjualan berlebih (overselling). Koordinat Geolocation HTML5 menyediakan data audit lokasi pengantaran yang akurat, disertai pemulihan stok otomatis saat pembatalan.
